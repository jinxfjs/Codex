# 扩展与复用

当前是单项目骨架。正式研究方向确定后保留相同分层，替换数据适配与分析模块。

## NHANES–MASLD 下一步

1. 冻结 `PROTOCOL.md` 与 `ANALYSIS_PLAN.md` 中的周期、目标人群、操作性定义和目标估计量。
2. 新增 `ingest_nhanes` 适配层：读取所选原文件，验证来源校验和，输出标准化字段及组件合并日志。
3. 新增 `harmonize` 层：按周期处理命名、单位、缺失码和类别差异，保留映射表与验证记录。
4. 新增 `phenotypes` 层：将已确认的临床定义实现为独立函数；对阈值、缺失、排除和冲突情况建立独立样例。
5. 新增调查设计与分析层：明确权重、分层、PSU、周期及子总体；选择支持复杂抽样估计的工具并锁定依赖。
6. 用独立软件或手工可验证的小样本核对关键队列人数与估计量，之后才新增真实数据运行入口。

保持演示入口对真实模式的拒绝，在单独的正式入口中实施上述流程，避免演示描述统计被当成正式估计。
如果采用 R 或其他统计工具，在独立 `analysis/` 下添加脚本、环境锁文件和命令行入口；当前版本没有预装这些依赖。

## 改为其他研究

| 主题 | 保留 | 需要替换或新增 |
| --- | --- | --- |
| NEISS | 配置、来源登记、字典、筛选日志、溯源 | 数据适配、编码映射、研究定义及设计型分析方案 |
| 肝移植 | 同上 | 受限数据接入、时间起点、随访、事件与删失规则、相应模型 |
| 其他公开数据研究 | 同上 | 研究变量、数据结构与适合的估计方法 |

这些是扩展位置，不是已经实现的数据连接或统计方法。
如多个研究并行，可迁移为 `projects/<study_id>/` 各自保存配置、字典和方案，共享通用校验工具；在确有第二个项目时再重构。
