## 当前演示实际执行的内容

- 数据字典校验：类型、必填、范围、类别、唯一键、合成标记。
- 顺序筛选：年龄非缺失 → 年龄 ≥ 演示边界 → 暴露非缺失 → 结局非缺失。
- 演示完整案例仅针对暴露和结局，不因 sex 缺失而排除。
- 输出未加权记录数、年龄均值、人工二元标记均值、sex 类别计数与缺失数。
- 不使用 `survey_weight` 估计统计量；`stratum` 和 `psu` 仅检查格式。
